# Ubuntu Homelab — Read-Only Security Audit

**Date:** November 10, 2026  
**Status:** **Point-in-time, read-only local configuration review; not a penetration test**

## Audit coverage

Reviewed UFW configuration, Docker-published ports, IPv4 and IPv6 `DOCKER-USER` rules, firewall counters, IPv6 forwarding, SSH server authentication settings, sampled SSH login activity, and container privileged/networking modes.

## Verified findings

| Area | Observed result |
| --- | --- |
| UFW | Active, inbound default deny |
| Allowed access | Home LAN and Tailscale permitted by policy |
| Docker forwarding | Custom forwarding restrictions present |
| IPv4/IPv6 | Both `DOCKER-USER` rule sets reviewed |
| SSH password auth | Disabled |
| SSH public-key auth | Enabled |
| SSH root password login | Prohibited |
| SSH X11 forwarding | Disabled |
| Sampled SSH logs | No suspicious entries identified in the sample |
| Docker containers | All **nine running containers** reported `Privileged=false` |

These findings are configuration and sampled-observation results. They **do not** independently establish that all external access is blocked or every component is secure.

## Relevant read-only commands

These are **repeatable reference examples**; the handoff did not provide a complete verbatim transcript.

```bash
sudo ufw status verbose
sudo iptables -S DOCKER-USER
sudo ip6tables -S DOCKER-USER
sudo iptables -L DOCKER-USER -nv
sudo ip6tables -L DOCKER-USER -nv
sysctl net.ipv6.conf.all.forwarding
sudo sshd -T
sudo journalctl -u ssh --since '24 hours ago'
sudo docker ps --format 'table {{.Names}}\t{{.Status}}'
```

A separate `docker inspect` review checked privilege modes; the exact command/output was not included in this handoff. Published port inventory was reviewed without publishing private or external addresses.

## Remaining review items

- Examine mounted `/var/run/docker.sock` and other privileged filesystem mounts.
- Audit added Linux capabilities and container security options, not just `Privileged=false`.
- Verify router port-forwarding and exposure from outside the home network.
- Assess application-level authentication, updates and network segmentation as appropriate.

## Security interpretation

`Privileged=false` is a useful control but **does not mean an unprivileged or isolated container** if it has sensitive mounts, capabilities or broad networking access. Firewall rule presence does not by itself prove internet reachability. The absence of suspicious log entries within a sample is not a comprehensive intrusion investigation.

**Result:** Documented an improved security baseline and transparent follow-up scope; no external penetration test or full security certification is claimed.
